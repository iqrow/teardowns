---
term: Map size
aka: [world size, number of players]
kind: knob
plain: How many tiles or systems the map holds, usually set with the number of players.
does: Sets how long the land grab lasts and when empires first meet.
ask: When does free land run out, and when do rivals first meet?
range: From duel maps for two players to huge maps for a dozen or more.
trouble: "Too much land per player: no contact for a long time. Too little: war before there is an economy to fight it."
sources:
  - work: 2k-civ5-manual
    page: Map Size
    quote: "The size of the map you choose will also determine the number of civilizations and city-states in the game."
at: [0.65, -0.35, 0.02]

term: Accelerator with a brake
aka:
  - speed and gate
kind: pattern
plain: A fast path increases flow while an independent gate limits what can continue. The useful system tunes both together, and builds the brake before the accelerator.
ask: What accelerates the work, and what stops unsafe output before it spreads?

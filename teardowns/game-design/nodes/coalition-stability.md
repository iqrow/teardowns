term: Core stability test
aka: [blocking-deviation test, core membership]
kind: measure
plain: "Under a specified transferable-utility coalition model, a core-stability test asks whether any coalition can block an outcome by making all its members better off. It is not a universal test for every alliance-stability concept. [MODEL ASSUMPTION]"
does: Exposes coalitions that exist only because alternatives or deviations are hidden from the test.
ask: Under the declared coalition values and continuation assumptions, is there a blocking coalition that can make all of its members better off?
range: Core-stable; blocked; multiple or empty core under the stated model
trouble: Under this core model, a pair can block a grand-coalition outcome if both improve by leaving; if several splits pass, the core test alone does not choose among them. [INFERENCE]

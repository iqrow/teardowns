---
term: Redundant coding
aka: [more than colour]
kind: concept
plain: Redundant coding carries the same meaning through colour plus a visible alternative such as shape, label, position, line type or pattern.
does: Lets players identify critical state when colours merge, dim or are unavailable.
ask: If the colour disappeared, which visible cue would still carry the meaning?
cues:
  - Two same-colour markers use different silhouettes
  - A pattern or line type repeats the distinction in a legend and on the board
  - Labels sit beside marks instead of requiring a distant colour match
range: Use colour as a speed cue while shape, label, pattern, line type or position carries the invariant meaning.
trouble: A player must compare distant swatches, remember a colour name, or guess a role after the hue disappears.

term: Economy
kind: pattern
plain: An internal economy is a system in which resources are produced, exchanged and consumed. Its feedback can create growth, scarcity, equilibrium or other shapes; it is not inherently reinforcing.
does: Turns resource flows into strategic choices about scarcity, investment, exchange and spending.
ask: Which resources exchange or convert into value?

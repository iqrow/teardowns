---
term: Visual encoding
aka: [meaning through appearance]
kind: part
plain: "Visual encoding assigns visible differences in colour, lightness, shape, pattern, position and emphasis to game information so players can read state and act."
does: Makes important state legible at a glance without forcing the player to decode a distant legend.
ask: Which visible difference carries each piece of game information, and can it survive the way the game is viewed?
cues:
  - Repeated markers keep a stable shape while their state changes
  - A legend or label matches marks on the playfield and interface
  - Colours, outlines and patterns separate roles without hiding the scene
range: Colour alone, colour plus redundant marks, or a fully non-colour visual language.
trouble: Different meanings collapse into the same appearance, or a temporary highlight is mistaken for identity.

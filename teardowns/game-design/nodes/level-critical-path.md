term: Critical path
aka: [golden path, main route]
kind: measure
plain: The critical path is the main intended route or procedure for completing a single-player level while encountering its important beats.
does: Communicates progression and helps scope optional spaces against must-see content.
ask: What ideal route should carry the player through the level's key beats?
range: A minimum route to complete a level through a golden path with numbered beats; it is an ideal, not a prediction of every player's route.
trouble: The main route is unclear, optional content hides the required beats, or the map's scope exceeds the experience goal.

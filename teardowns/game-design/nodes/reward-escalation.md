---
term: Reward escalation
aka: [more payoff for more success]
kind: knob
plain: The reward for a successful action increases the resources or options available for the next action.
does: Sets how strongly success compounds.
ask: Does this reward create useful momentum or remove future choices?
range: reward size and delay

---
term: Commitment device
aka: [lock-in, observable promise, bridge-burning move]
kind: knob
plain: A commitment device removes, delegates or changes a future option so another player can predict the committed response. It works only when the constraint is real, observable enough to be believed and still compatible with the intended play.
does: Changes the future game before the other player chooses, often by trading flexibility for credibility.
ask: Which future action becomes unavailable or costly, and can the other player see that it really changed?
range: Irreversible action; delegated choice; posted stake; public conditional promise
trouble: A hidden or reversible pledge is cheap talk; an overstrong lock-in can leave no graceful exit when the state changes. [INFERENCE]

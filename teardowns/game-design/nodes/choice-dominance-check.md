---
term: Dominance check
aka: [is one option always better?]
kind: measure
plain: Compare each action's costs and consequences across representative states and player goals. An option is dominated if another is never worse on the relevant criteria and is better on at least one; a popular option alone does not prove dominance.
does: Finds false alternatives that add menu complexity without a real trade-off.
ask: Can I name a reachable state where each option earns its place?
range: Record state, goal, costs, exposure and future options; mark a witness state for each viable alternative.
trouble: Experienced players repeat the same action regardless of ammo, threat, position or objective.

deeper: Strict versus weak dominance, mixed strategies, goal-dependent value and representative-state sampling.

term: Drain and stop threshold
aka: [the brake setting]
kind: knob
plain: A drain removes resource, and a stop threshold decides when the loop can no longer continue.
does: Sets the regulating force and the point at which activity stalls.
ask: How much drain preserves choice without making the loop inert?
cues:
  - Resource falling each cycle
  - Activity stopping when resource is too low
range: drain per cycle; minimum viable resource
at: [0, 0, 0.16]

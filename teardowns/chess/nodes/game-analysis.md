---
term: Game analysis
aka:
  - post-game review
  - self-analysis
kind: process
plain: Game analysis reconstructs a played game, marks critical decisions and errors, and explains the human cause before consulting tools or comparisons. The output is a small set of named lessons linked to positions, not a string of engine numbers.
does: Converts a result and its turning points into concrete training positions and an updated pattern catalogue.
ask: Where did the evaluation or plan change, what did I miss, and what repeatable test would catch it next time?
cues:
  - Reconstructed game
  - Critical decisions and errors marked
  - Lessons linked to positions
trouble: The review becomes outcome-based blame, or an engine line is copied without understanding the decision that produced the error.

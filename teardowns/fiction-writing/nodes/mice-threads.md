---
term: MICE threads
aka: [MICE quotient, story threads, nested plots]
kind: concept
plain: "Four kinds of story thread: milieu, inquiry, character and event. Each opens and closes, and threads nest like Russian dolls."
does: Tells you how each thread must end, and that inner threads close before outer ones.
ask: Which thread did I open first, and does the ending close it?
trouble: The ending answers the wrong question, so the book feels unfinished.
at: [-0.5, 0.4156, 0.012]
pattern: pattern-nested-units
variants:
  - label: Thread
    items:
      - id: milieu
        name: Milieu
        plain: Starts when the character enters a place and ends when she leaves it.
        why: A milieu thread opens when a character enters a place and closes when she leaves, not merely because a place appears.
        sources:
          - {work: mary-robinette-kowal-et-al-what-is-the-m-i-c-e, page: transcript, quote: "Milieu stories are driven by place, beginning when a character enters a place and end when they exit"}
      - id: inquiry
        name: Inquiry
        plain: Starts with a question and ends when it is answered. Who wrote the list?
        sources:
          - {work: mary-robinette-kowal-et-al-what-is-the-m-i-c-e, page: transcript, quote: "Inquiry stories begin with a question and end when the character answers it."}
      - id: character
        name: Character
        plain: Starts with a character unhappy with who she is; ends when she changes or accepts herself.
        sources:
          - {work: mary-robinette-kowal-et-al-what-is-the-m-i-c-e, page: transcript, quote: "Character stories start with “Who am I?” and end with recognition of self."}
      - id: event
        name: Event
        plain: Starts when the normal order breaks; ends when an old or new order is set.
        sources:
          - {work: mary-robinette-kowal-et-al-what-is-the-m-i-c-e, page: transcript, quote: "Event stories are action, starting with disruption, and ending with return to normal or establishing a new normal"}
sources:
  - {work: mary-robinette-kowal-et-al-what-is-the-m-i-c-e, page: transcript, quote: "M.I.C.E. is an organizational tool which categorizes story elements as Milieu, Inquiry, Character, or Event."}
  - {work: mary-robinette-kowal-et-al-nesting-threads-in, page: transcript, quote: "Nesting threads, or first in, last out."}

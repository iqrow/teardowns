term: Set point
aka:
  - target
  - goal
  - quality bar
  - thermostat setting
kind: pattern
plain: The level a braking engine pulls toward; a review compares the current state with it and acts on the gap. In environment art the set points are a target image, a value plan and a performance budget.
ask: "What does this review compare against: a set point, or the last round?"
trouble: Without a set point, each round can be judged against the one before, so small errors add up and the look drifts. This is the drifting goals trap.
